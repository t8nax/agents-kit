# agents-kit

Плагин для Claude Code и Codex, с которым агент сам ведёт инженерную работу над проектом, а к человеку обращается только тогда, когда без него не обойтись.

Всё, что агент знает о проекте, хранится в отдельном git-репозитории — базе знаний. Она лежит рядом с кодом, но не внутри него. Когда вы открываете Claude Code или Codex в проекте, связанном с базой, агент первым делом читает это знание.

Базу можно вести вместе с коллегами. Ваш порядок работы, то, что агент решает без вас, бэклог и заметки о текущих задачах лежат в личном репозитории внутри базы: коллеги его не видят и поправить не могут. Порядком работы можно поделиться — он появится в вашей папке в базе, и коллега возьмёт его себе целиком или частями. Поэтому при подключении агент спросит ваше имя в базе, например `b-ignatyev`. Общие задачи команда ведёт в своём трекере: в базе сказано, где он, а агент берёт оттуда задачу, назначает её на вас и показывает назначенные на вас задачи рядом с вашим бэклогом.

До коллег и до ваших других машин база доходит через свой `origin`, а личный репозиторий — через свой приватный remote: агент сам забирает изменения, когда берёт задачу, и отдаёт свои, когда их закоммитил. Если две правки столкнутся, агент спросит, какая верна. Нет remote — всё остаётся на этой машине.

Чтобы подключить проект, откройте в нём агента и вызовите скилл `onboard`. Потом опишите с агентом, в каком порядке проект ведёт задачи, — скилл `flow`, а если команда ведёт задачи в трекере — где он и что агенту в нём делать, скилл `tracker`. Чтобы дать агенту задачу — скилл `drive`.

Скиллы кита — `onboard`, `flow`, `tracker`, `drive`, `backlog` и `worktree`. В Claude Code скилл зовут через косую черту — `/drive`, в Codex через знак доллара — `$drive` — или выбирают в списке `/skills`. Агент зовёт скилл и сам, если попросить словами: «возьми задачу», «покажи бэклог».

## Установка

Если вы просто пользуетесь китом, поставьте его из маркетплейса:

```powershell
claude plugin marketplace add t8nax/agents-kit
claude plugin install agents-kit@agents-kit
```

Если вы правите сам кит, склонируйте репозиторий и сделайте ссылку на его папку `plugin` в `~/.claude/skills/`. Тогда Claude Code берёт кит прямо из клона, и правки видны сразу, без выпуска версий:

```powershell
git clone https://github.com/t8nax/agents-kit <папка клона>
New-Item -ItemType Junction -Path "$env:USERPROFILE\.claude\skills\agents-kit" -Target <папка клона>\plugin
```

Выберите что-то одно: два кита одновременно ставить нельзя.

### Codex

В Codex кит ставится тем же маркетплейсом:

```powershell
codex plugin marketplace add t8nax/agents-kit
codex plugin add agents-kit@agents-kit
```

Codex по умолчанию пишет только внутри открытого проекта и не ходит в сеть, а киту нужно писать в базу знаний рядом с проектом и отдавать её на сервер. Без доступа Codex будет спрашивать разрешение на каждую запись в базу и каждую отправку. Кит ваши настройки Codex не правит — допишите в `~/.codex/config.toml` сами, указав папку базы:

```toml
[sandbox_workspace_write]
writable_roots = ['C:\путь\к\базе']
network_access = true
```

В Codex кит работает так же, как в Claude Code, с двумя отличиями:

- **Помощников этапов нет.** Этап, который во флоу проходит субагент, агент Codex сам не пройдёт, а спросит вас, как быть.
- **Ответа агент не дожидается сам.** Когда вся работа упирается в ваш ответ, агент Codex останавливается сводкой. Впишите ответ в файл памяти задачи и напишите агенту «продолжай».

## Обновление

**Из маркетплейса.** Удобнее всего один раз включить автообновление: `/plugin` → **Marketplaces** → `agents-kit`. По умолчанию оно выключено. Без него обновляйте руками:

```powershell
claude plugin marketplace update agents-kit
claude plugin update agents-kit@agents-kit
```

Новая версия заработает в следующей сессии Claude Code, уже открытые продолжат работать на старой.

В Codex — так:

```powershell
codex plugin marketplace upgrade agents-kit
```

По номеру версии видно, сколько возни будет после обновления:

- поменялась последняя цифра (`0.4.1` → `0.4.2`) — просто обновитесь;
- поменялась средняя (`0.4.2` → `0.5.0`) — может поменяться устройство базы знаний. Тогда первая же сессия остановится и предложит перевести базу. Кит переведёт её сам и закоммитит, а если понадобится, сначала что-то у вас спросит, например ваше имя в базе. Незаконченную работу других сессий проекта перевод не трогает: после него они продолжают с новой сессии.

**Из клона.** Сделайте `git pull` в папке клона. В уже открытой сессии выполните `/reload-plugins`, новые сессии подхватят изменения сами.

## Удаление

**Из маркетплейса:**

```powershell
claude plugin uninstall agents-kit@agents-kit
claude plugin marketplace remove agents-kit
```

В Codex:

```powershell
codex plugin remove agents-kit@agents-kit
codex plugin marketplace remove agents-kit
```

**Из клона** — удалите ссылку. Сам клон останется на месте:

```powershell
Remove-Item "$env:USERPROFILE\.claude\skills\agents-kit"
```

Базы знаний и настройки связи в проектах (ключи `agents-kit.*` в `git config`) при удалении остаются. Без кита они ни на что не влияют, а если поставить кит снова, всё заработает как раньше.
