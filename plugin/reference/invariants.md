# Инварианты agents-kit

Модель: **агент делает инженерную работу, оператор — только то, чего агент не может**: принимает необратимое решение, даёт доступ, пишет коллеге.

## Три слоя, которые не смешиваются

| Слой | Где живёт | Кто правит |
|---|---|---|
| механизм | клон кита | только сессия, открытая в самом ките |
| знание проекта | отдельный репозиторий базы знаний, вне кода | рабочая сессия и оператор |
| код | рабочая копия проекта | команда проекта |

## Действует всегда

- **В репозиторий проекта знание не пишется, и каталог знания в нём не создаётся.** `CLAUDE.md` и `.claude/skills/` в нём принадлежат проекту; субагентов базы кладёт в рабочую копию только `agents-deploy.ps1` — мимо git проекта и не трогая отслеживаемые им файлы, а сессия туда не пишет.
- **Кит не правится из рабочей сессии** — ни клон, ни установленная копия. Задача требует правки кита — это вопрос оператору, а работа идёт тем китом, что есть.
- **Ничего не пишется молча.** Файл базы меняет только явная правка, и агент говорит, что записал. Свободный разговор не фиксирует ничего.
- **Задача живёт файлом памяти своей рабочей копии:** есть файл — задача в работе, нет — не в работе. Другой пометки занятости нет; памяти чужой копии сессия не касается.
- **Одна рабочая копия — одна задача за раз.** Вторая параллельная — в новом `git worktree`.
- **Пока памяти нет, по задаче не делается ничего, кроме самого взятия:** ни стадия флоу, ни правка кода.
- **Что нужно от оператора — вопрос в разделе «Оператору» памяти задачи, ответ — его строка `ответ:`.** Пока память заведена, оператор спрашивается только так — не инструментом вопроса и не репликой с ожиданием ответа. Ответ пишет оператор; сессия его не сочиняет. Сессия, у которой вся работа ждёт ответа, не засыпает, а ждёт свой файл.
- **Критерий закрытия записывается до первой стадии флоу,** и молча за него не выходят: понадобилось больше — вопрос оператору.
- **Задача закрывается выполненным критерием и пройденным флоу, а не мержем ветки.**
- **Работа идёт по флоу проекта:** стадия без записанного выхода не пройдена, без своего условия не пропускается, назад флоу идёт только названным возвратом; в базу пишет оркестратор, а не субагент. Стадия против инварианта — вопрос оператору.
- **Прогресс не имитируется:** шаг закрывает проверка, а не намерение; отпавший шаг — названная причина.
- **Замеченное вне критерия записывается в `backlog.md` базы сразу** и без решения оператора попутно не делается. Запись в работу выбирает оператор, если флоу не задал иного.
- **Решения проекта читаются до первой стадии флоу** — по поданному оглавлению `decisions/`, те, которых задача касается. Неизвестное решение не отменяется тем, что его не прочли.
- **Знание фиксируется в конце работы:** то, что дорого переоткрывать, — решение с причиной, понятое про продукт, сдвинутая граница. Память задачи — не знание.
- **Правила читаются до первой записи:** в базу — `base-layout.md`, в память задачи — `task-memory.md`, в бэклог — `backlog-record.md`. Пути поданы в начале сессии.
- **Коммит в базу — явными путями:** `git commit -m "…" -- <пути>`, новый файл — точечным `git add`. Никогда `git add -A`, `git add .`, `checkout`, `stash`, `reset` в базе. Код коммитится в рабочую копию, знание — в базу.
- **Секреты не попадают в git базы** — ни токены, ни строки подключения, ни локальный пароль, «заведомо непригодный» вне этой машины. В коммит идёт политика; значение живёт там, где его читает код, а в базе — только в `local/` вне git.
- **Язык базы знаний — русский.** Язык кода, тестов и коммитов задаёт проект.
