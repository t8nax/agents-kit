# Бэклог

Читает сессия, которая показывает бэклог, пишет в него или берёт из него запись, — до первой записи в `backlog.md`. Что ещё лежит в базе — `base-layout.md` рядом.

`backlog.md` — не очередь: статусов нет, номер — имя записи, а не место.

```markdown
следующий номер: B-13

## B-12 <о чём дело, одной фразой>

<текст оператору>

### Агенту
- <подробность для того, кто возьмёт запись>
- где: <файл, место>
```

## Запись

Запись — раздел `##` до следующего `##`; под заголовком подряд идут пары `ключ: значение` включённых полей, после пустой строки — текст оператору. `### Агенту` делит запись на две части так же, как память задачи, и текст оператору пишется по тем же правилам — `task-memory.md`, «Две части памяти».

- **Одна запись — одно дело, и одно дело — одна запись.** Новая запись заводится, когда в прочитанном файле нет записи о том же деле: нашлась — новая не заводится и оператору называется её номер; похоже, но не то же — запись заводится, и оператору называются оба номера.
- **Запись читается без сессии, которая её записала.** Критерия закрытия в ней нет — его пишут при взятии.
- **В «Агенту» — всё, что нужно взявшему:** имена кода, пути, что уже выяснено, по мысли на строку. Строка `- где:` — когда место известно.
- **Пишут двое.** Оператор — руками или просьбой в любой сессии под китом. Сессия — сама, когда заметила нужное, но не нужное критерию задачи: сразу, а не на фиксации. Что записано, сессия говорит оператору.
- **Запись дописывается в конец файла точечной правкой; чужие не переписываются.**

## Поля

Поля включает строка `поля:` в шапке — имена через запятую; заводит её оператор, руками или просьбой. Строки нет — записи полей не несут.

```markdown
следующий номер: B-13
поля: приоритет, тип

## B-12 <о чём дело, одной фразой>

приоритет: высокий
тип: баг
```

| Поле | Значение |
|---|---|
| `приоритет` | `низкий` · `средний` · `высокий` · `блокер` |
| `тип` | `баг` · `фича` |

- **Перечень закрытый:** ни своего поля, ни своего значения не заводят.
- **Объявленное поле есть у каждой записи.** Значение называет оператор; не назвал — сессия ставит его по тексту записи и говорит оператору, что поставила.

Имя в строке `поля:` не из таблицы, пустое значение и значение вне перечня — красная находка сверки; запись без объявленного поля и поле, в шапке не объявленное, — предупреждение.

## Номер

- **Номер `B-N` не переиспользуется:** номер взятой или отклонённой записи новой не достаётся. Выдаёт номер счётчик `следующий номер:` в шапке. Пишется латиницей; кириллическая `В-7` в словах оператора — тот же номер.
- **Номер выдаётся правкой счётчика до записи.** Прочитать файл с диска, точечной правкой поднять счётчик на число новых записей, потом дописать записи. Правка не нашла прежний текст — счётчик подняла соседняя копия: перечитать и выдать заново. Блокировки сверх этого нет.
- **Запись без номера** (дописана руками) получает номер тем же счётчиком, по порядку в файле, когда её нумерует `/backlog`. Счётчика нет — он ставится за наибольшим номером.

Повтор номера и счётчик не выше наибольшего номера — красная находка сверки; запись без номера и файл без счётчика — предупреждение.

## Взять и удалить

- **Взять запись — сначала вырезать её, потом завести память.** Вырезается ровно эта запись, от её заголовка до следующего, точечной правкой по её тексту. Память заводится по `task-memory.md`, часть «Агенту» записи переносится в её «Факты», поля — никуда. Записи уже нет — её взяла соседняя копия или удалил оператор: задача не начинается, памяти не заводить, сказать оператору. Пометки «взята» нет: занятость отмечает только файл памяти.
- **Запись удаляется**, когда её взяли, сделали попутно по решению оператора или оператор её отклонил. `backlog.md` не архив.

В подачу хука бэклог не входит и потолка не имеет.
