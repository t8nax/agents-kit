# Бэклог

Читает сессия, которая показывает бэклог, пишет в него, берёт из него запись или по слову оператора переписывает, удаляет и объединяет записи, — до первой записи в `backlog.md`. Что ещё лежит в базе — `base-layout.md` рядом.

`backlog.md` — не очередь: статусов нет, номер — имя записи, а не место.

```markdown
следующий номер: ORD-13

## ORD-12 <что изменится, одной фразой>

<текст оператору>

### Агенту
- <подробность для того, кто возьмёт запись>
- где: <файл, место>
```

## Запись

Запись — раздел `##` до следующего `##`; под заголовком подряд идут пары `ключ: значение` включённых полей, после пустой строки — текст оператору. `### Агенту` делит запись на две части так же, как память задачи, и текст оператору пишется по тем же правилам — `task-memory.md`, «Две части памяти».

- **Две записи про одно не заводятся.** Про одно — значит, когда их сделают, оператор увидит одно и то же. Разные файлы и разные упавшие проверки бывают одной записью.
- **Заголовок говорит, что изменится, когда запись сделают,** а не где сломалось. По заголовкам записи и сравнивают.
- **Перед новой записью читаются заголовки записей** — поиском `^## `, а не файл целиком. Заголовок похож — прочитать ту запись.
- **Такая запись уже есть — новую не заводить:** свой случай дописать строкой в её «Агенту», оператору назвать её номер.
- **Похоже, но не то же** — завести новую и назвать оператору оба номера. Тянет написать «чинить вместе с ORD-9» — значит запись одна.
- **Запись читается без сессии, которая её записала.** Критерия закрытия в ней нет — его пишут при взятии.
- **В «Агенту» — всё, что нужно взявшему:** имена кода, пути, что уже выяснено, по мысли на строку. Строка `- где:` — когда место известно.
- **Пишут двое.** Оператор — руками или просьбой в любой сессии под китом. Сессия — сама, когда замеченное по инвариантам уходит в бэклог, а не в починку задачи, и когда оператор сузил критерий задачи, переросшей сценарий, — `/drive`: сразу, а не на фиксации. Что записано, сессия говорит оператору.
- **Запись дописывается в конец файла точечной правкой.** В чужую запись сессия сама добавляет только то, чего в ней нет: строку случая в «Агенту» и сам заголовок `### Агенту`, номер, включённое поле; заголовок записи и текст оператору она не трогает. Переписывает, объединяет и удаляет записи, кроме взятой в работу, сессия только по слову оператора — «Взять, переписать, удалить, объединить».

## Поля

Поля включает строка `поля:` в шапке — имена через запятую; заводит её оператор, руками или просьбой. Строки нет — записи полей не несут.

```markdown
следующий номер: ORD-13
поля: приоритет, тип

## ORD-12 <что изменится, одной фразой>

приоритет: высокий
тип: баг
```

| Поле | Значение |
|---|---|
| `приоритет` | `низкий` · `средний` · `высокий` · `блокер` |
| `тип` | `баг` · `фича` |

- **Перечень закрытый:** ни своего поля, ни своего значения не заводят.
- **Объявленное поле есть у каждой записи.** Значение называет оператор; не назвал — сессия ставит его по тексту записи и говорит оператору, что поставила.

Имя в строке `поля:` не из таблицы, пустое значение и значение вне перечня — красная находка сверки; запись без объявленного поля и поле, в шапке не объявленное, — предупреждение.

## Номер

Номер — буквы проекта и число: `ORD-12`. Буквы называет проект, когда заводит базу, и держит их строка `следующий номер:` в шапке; у всех записей базы они одни.

- **Номер не переиспользуется:** номер взятой или удалённой записи новой не достаётся. Выдаёт номер счётчик `следующий номер:` в шапке.
- **Номер выдаётся правкой счётчика до записи.** Прочитать файл с диска, точечной правкой поднять счётчик на число новых записей, потом дописать записи. Правка не нашла прежний текст — счётчик подняла соседняя копия: перечитать и выдать заново. Блокировки сверх этого нет.
- **Буквы — латиница и цифры, первый знак буква, не больше десяти знаков; пишутся в верхнем регистре.** Своих букв запись не заводит, и сессия новых не придумывает: нет ни счётчика, ни записи с номером — спросить оператора.
- **Буквы у базы одни на всё время.** `backlog.md` заводится заново — буквы берутся из номеров в живых памятях задач: названные иначе оставят взятые записи неопознанными.
- **В словах оператора регистр и кириллические двойники букв ничего не значат:** `В-7` и `b-7` — тот же номер, что `B-7`.
- **Запись без номера** (дописана руками) и запись чужими буквами получают номер тем же счётчиком, по порядку в файле, когда их нумерует `/backlog`. Счётчика нет — он ставится за наибольшим номером.

Повтор номера, номер чужими буквами и счётчик не выше наибольшего номера — красная находка сверки; запись без номера и файл без счётчика — предупреждение.

## Взять, переписать, удалить, объединить

- **Названная номером запись находится поиском её заголовка `##`,** а не чтением файла целиком. Названа описанием — найти по заголовкам, назвать оператору номер и заголовок найденной и действовать после его ответа. Записи уже нет — её взяла соседняя копия или удалил оператор: ничего не править, сказать оператору.
- **Правка точечная, по тексту, прочитанному с диска.** Правка не нашла прежний текст — файл поменяла соседняя копия: перечитать и повторить.
- **Взять запись — сначала вырезать её, потом завести память.** Вырезается ровно эта запись, от её заголовка до следующего, точечной правкой по её тексту. Память заводится по `task-memory.md`, часть «Агенту» записи переносится в её «Факты», поля — никуда. Записи нет — задача не начинается, памяти не заводить. Пометки «взята» нет: занятость отмечает только файл памяти.
- **Переписать.** Меняется то, что назвал оператор: заголовок, текст оператору, «Агенту», значения полей. Номер не меняется. Заголовок и текст оператору пишутся по правилам «Записи». Новое значение поля — только из перечня «Полей»; вне перечня — не писать, а назвать оператору допустимые значения.
- **Сменилась суть записи** — сверить новый заголовок с заголовками остальных записей. Про то же, что другая запись, — назвать оператору оба номера и предложить объединить. Из «Агенту» убрать строки, которые к новому смыслу не относятся, и сказать оператору, что убрано.
- **Объединить.** Остаётся запись, которую назвал оператор; не назвал — с меньшим номером. Её заголовок и текст оператору переписываются по правилам «Записи» так, чтобы вместить то, что было только в другой; в её «Агенту» переносятся строки другой, которых там нет. Значения полей разошлись — значение называет оператор; не назвал — сессия ставит его по тексту и говорит, что поставила. Другая запись удаляется; номера её в остающейся нет.
- **Удалить — вырезать запись так же, как при взятии.** Запись удаляется, когда её взяли, сделали попутно по решению оператора, оператор её отклонил или её поглотила другая при объединении. `backlog.md` не архив.

Запись, оставшаяся в файле, когда память с её номером жива, — красная находка сверки на `backlog.md`: взявшая сессия дорезает вырез. Память не своей копии — находка помечена «решает оператор».

В подачу хука бэклог не входит и потолка не имеет.
