# Глоссарий

Читает сессия проекта под китом, которой нужно значение слова кита.

- **Артефакт** — файл или ссылка вне памяти задачи или записи бэклога, который открывают, чтобы их понять: макет, спека, снимок экрана, лог.
- **База знаний, база** — отдельный репозиторий со знанием проекта: что за система, чего нельзя любому агенту проекта, какие решения действуют, где трекер задач, папки операторов с выложенными ими флоу и субагентами; в `local/` вне её git — личный репозиторий оператора этой машины.
- **Бэклог** — `backlog.md` личного репозитория: что стоит сделать или решить и сейчас не в работе.
- **Вобрать ответ** — перенести ответ оператора из памяти задачи туда, где он действует.
- **Вопрос оператору** — что нужно от оператора, записанное в разделе «Оператору» памяти задачи.
- **Выход** — чем подтверждается, что этап пройден.
- **Запись бэклога** — раздел `backlog.md`: одно, что изменится, когда его сделают.
- **Имя оператора** — имя его папки в `people/` базы, одно на машину, хранится в `local/me.json` базы.
- **Инварианты** — правила, которые действуют в каждой сессии под китом.
- **Исполнитель** — чья работа даёт выход этапа.
- **Критерий закрытия** — проверяемый признак «сделано» задачи.
- **Личный репозиторий** — `local/me/` базы, свой git оператора: рамки агента, флоу, субагенты, бэклог, память задач и их артефакты. Общая база его не видит.
- **Механизм** — файлы `plugin/` репозитория кита: то, что ставится пользователю кита.
- **Находка** — что сверка нашла в базе не так: красная или предупреждение.
- **Основная копия** — репозиторий проекта или один его каталог, который связывают с базой.
- **Оператор** — человек, который делает то, чего агент не может.
- **Оркестратор** — сессия `/drive`, которая ведёт задачу по сценарию.
- **Память задачи** — файл в `work/` личного репозитория, где рабочая копия ведёт свою задачу, и рядом с ним флоу задачи — её сценарий с этапами, скопированный из флоу при взятии.
- **Папка оператора** — `people/<имя>/` базы: флоу и субагенты, которые оператор выложил для коллег; агент по ней не работает.
- **Подача** — что хук передаёт сессии на старте.
- **Помощник** — субагент, которого оркестратор зовёт на кусок своей работы на этапе.
- **Потолок** — наибольшее число строк файла базы, у артефакта — наибольший размер файла.
- **Рабочая копия** — папка с кодом проекта, где открыта сессия: основная копия или её git worktree.
- **Рабочий контур** — ведение задачи через `/drive`: от взятия до фиксации знания.
- **Разрыв** — связь копии с базой не сошлась.
- **Решения** — файлы `decisions/` базы: как договорились делать систему и почему.
- **Сверка** — проверка базы на правила кита.
- **Связь** — указатель и список копий, которые сходятся.
- **Список копий** — поле `workspaces` в `local/me.json` базы: какие основные копии этой машины база числит своими.
- **Справки** — файлы `reference/` кита, которые сессия читает посреди работы.
- **Сценарий** — именованный список этапов и возвратов между ними в `flow/scenarios.md` личного репозитория; взятую задачу ведут до закрытия одним сценарием — тем, что скопирован во флоу задачи.
- **Тест входа** — вопрос к строке знания, который решает, идёт ли она в базу.
- **Трекер** — внешний сервис, где команда ведёт свои задачи; описан в `tracker.md` базы.
- **Указатель** — ключ в локальном git config копии: где база репозитория или одного его каталога.
- **Фиксация знания** — запись знания в базу в конце работы.
- **Флоу** — каталог `flow/` личного репозитория: сценарии и этапы, которыми оператор ведёт задачи проекта.
- **Хук** — скрипт кита, который Claude Code запускает сам.
- **Шаг** — работа внутри открытого этапа.
- **Этап** — часть пути задачи со своим выходом, описан файлом в `flow/stages/` личного репозитория.
