# Глоссарий

Читает сессия проекта под китом, которой нужно значение слова кита.

- **Артефакт** — файл или ссылка вне памяти задачи, который открывают, чтобы её понять: макет, спека, снимок экрана.
- **База знаний, база** — отдельный репозиторий со знанием проекта: что за система, где граница решений агента, какие решения действуют, флоу, бэклог и память задач.
- **Бэклог** — `backlog.md` базы: что стоит сделать или решить и сейчас не в работе.
- **Вобрать ответ** — перенести ответ оператора из памяти задачи туда, где он действует.
- **Вопрос оператору** — что нужно от оператора, записанное в разделе «Оператору» памяти задачи.
- **Выход** — чем подтверждается, что шаг флоу пройден.
- **Запись бэклога** — раздел `backlog.md`: одно дело.
- **Инварианты** — правила, которые действуют в каждой сессии под китом.
- **Исполнитель** — чья работа даёт выход шага флоу.
- **Критерий закрытия** — проверяемый признак «сделано» задачи.
- **Механизм** — файлы `plugin/` репозитория кита: то, что ставится пользователю кита.
- **Находка** — что сверка нашла в базе не так: красная или предупреждение.
- **Основная копия** — репозиторий проекта или один его каталог, который связывают с базой.
- **Оператор** — человек, который делает то, чего агент не может.
- **Оркестратор** — сессия `/drive`, которая ведёт флоу.
- **Память задачи** — файл в `work/` базы, где рабочая копия ведёт свою задачу.
- **Подача** — что хук передаёт сессии на старте.
- **Помощник** — субагент, которого оркестратор зовёт на кусок своей работы в шаге флоу.
- **Потолок** — наибольшее число строк файла базы.
- **Рабочая копия** — папка с кодом проекта, где открыта сессия: основная копия или её git worktree.
- **Рабочий контур** — ведение задачи через `/drive`: от критерия закрытия до фиксации знания.
- **Разрыв** — связь копии с базой не сошлась.
- **Решения** — файлы `decisions/` базы: как договорились делать систему и почему.
- **Сверка** — проверка базы на правила кита.
- **Связь** — указатель и список копий, которые сходятся.
- **Список копий** — `agents-kit.json` в корне базы: какие основные копии база числит своими.
- **Справки** — файлы `reference/` кита, которые сессия читает посреди работы.
- **Тест входа** — вопрос к строке знания, который решает, идёт ли она в базу.
- **Указатель** — ключ в локальном git config копии: где база репозитория или одного его каталога.
- **Фиксация знания** — запись знания в базу в конце работы.
- **Флоу** — `flow.md` базы: шаги, которыми на проекте ведут задачу от взятия до закрытия.
- **Хук** — скрипт кита, который Claude Code запускает сам.
- **Шаги работы** — работа внутри открытого шага флоу.
