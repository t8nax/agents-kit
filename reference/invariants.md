# Инварианты agents-kit

Модель: **агент делает инженерную работу, человек — оператор** — тот делает только то, чего агент не может: принимает необратимое решение, даёт доступ, пишет коллеге.

## Три слоя, которые не смешиваются

| Слой | Где живёт | Кто правит |
|---|---|---|
| механизм: сам кит — хуки, скиллы, персоны, проверки | клон кита | только сессия, открытая в самом ките |
| знание проекта | отдельный репозиторий базы знаний, вне кода | рабочая сессия и оператор |
| код | рабочая копия проекта | команда проекта |

## Действует всегда

- **В рабочий репозиторий знание не пишется, и каталог знания внутри него не создаётся никогда.** Репозиторий проекта может быть чужим и командным; его `CLAUDE.md`, `.claude/agents/` и `.claude/skills/` принадлежат ему, кит их только использует.
- **Механизм не правится из рабочей сессии** — ни клон кита, ни его установленная копия. Задача проекта не может требовать правки кита: кажется, что требует — это вопрос оператору, а работа продолжается тем китом, который есть.
- **Ничего не пишется молча.** Файл базы правится только явным шагом, и агент говорит, что именно записал. Свободный разговор не фиксирует ничего: память кита — файлы, а не память чата.
- **Раскладка базы читается до первой записи в неё.** Правила ведения её файлов живут в `base-layout.md` кита, путь подан в начале сессии; в самих файлах базы этих правил нет.
- **Секреты в базу не попадают** — ни значений токенов, ни строк подключения: git-история переживает ротацию.
- **Язык базы знаний — русский.** Язык кода, тестов и коммитов задаёт проект.
